# 番号抽選システム

イベント用の番号抽選ツールです。ブラウザだけで動きます（インストール不要）。

## 使い方

1. ページを開くとパスワード画面が出るので、パスワードを入力してログイン
2. 「抽選する」を押すと番号が回りだし、ドラムロールが鳴ります
3. もう一度押すと止まり、当選番号が大きく表示されて「ジャーン」が鳴ります
4. 当選した番号は画面下に順番に並んでいきます
5. 設定した人数に達すると「抽選終了」になります

**スペースキーでも同じ操作ができます**（1回目でスタート、2回目でストップ）。
パソコンで投影するときは、キーボードだけで回せます。

音を消したいときは右上の「🔊 音あり」を押すと「🔇 音なし」に切り替わります。

## 設定画面（⚙設定）

| 項目 | 内容 |
|---|---|
| 番号の範囲 | 抽選対象になる番号（例: 1〜100） |
| 当選者数 | 何人当たりにするか |
| 抜きたい番号（除外） | 抽選に出したくない番号。カンマ区切りで入力 |
| ログインパスワード | 次回ログインから有効 |

「抽選結果をすべて消す」を押すと、当選番号の履歴が消えて最初からやり直せます。

## 注意

- 当選番号と設定は**その端末のブラウザに保存**されます。別の端末・別のブラウザでは共有されません。抽選は1台の端末で最後まで行ってください。
- ブラウザのデータを消すと当選履歴も消えます。
- パスワードは操作ミス防止のための簡易ロックです。機密情報を扱うものではありません。
- 個人情報は一切入力・保存しません。
